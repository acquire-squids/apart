# apart

A work-in-progress toy programming language by Squiddy.

## About

I've been trying to learn programming language development for a few years, and this is my latest and greatest attempt.

It's been a ton of fun.

[YellowAfterlife's "A small guide on writing interpreters"](https://yal.cc/interpreters-guide/) was inspirational material back when I first became interested some time around 2022, and [Crafting Interpreters](https://craftinginterpreters) was an excellent learning resource of which I kept coming back to every few months to read more of and try it again with new knowledge.

### Why "apart"?
The name, combined with the fact that it will never be 100% finished (there's always more to do), is supposed to represent how I hope I'll never grow apart from my love of programming and creating programming languages.

## Notes
I don't know if I want to compile to an existing language, compile to assembly, or make an interpreter.  I may end up doing all three.  For now, it'll be everything but the final step and I'll interpret the IR to see it in action.

I'm a little lacking in theoretical knowledge and programming skills, but I do it anyway because it brings joy.
